# PKKM Aspek 5 — Prestasi &amp; Pengembangan Diri

Deck presentasi web (HTML) Laporan Kinerja PKKM Tahunan 2026, Aspek 5.
MTs Negeri 2 Kebumen.

## Membuka

Buka `index.html` di browser modern. Navigasi dengan tombol panah kiri/kanan,
atau langsung ke slide tertentu lewat hash `#/N` (mis. `#/5`).

## Struktur

- `index.html` — seluruh 18 slide
- `assets/` — CSS tema, runtime presentasi, animasi
- `media/logos/` — logo mitra
- `media/slide/` — gambar pendukung slide

Font Plus Jakarta Sans dimuat dari Google Fonts, sehingga perlu koneksi internet.
